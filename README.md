# ChocoScan Demo

A browser-based educational UI demo built with HTML, CSS, and vanilla JavaScript. It demonstrates simulated scan results and example warning dialogs. It is not a real security scanner and does not collect credentials or transmit user input.

## Planned structure

- `index.html` — demo hub and navigation
- `assets/css/style.css` — layout and visual styling
- `assets/js/app.js` — UI interactions
- `modes/` — separate demo modes

## Safety

All scan results are illustrative. Dialogs remain dismissible, and the demo does not lock pointer input, force navigation, open unsolicited tabs, or request passwords.
